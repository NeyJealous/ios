Название проекта

Инвестиционный помощник — система управления инвестиционным портфелем в Google Sheets на базе Google Apps Script с интеграцией с API Т-Инвестиций.

Основная цель

Создать профессиональную систему, которая:

автоматически загружает данные из Т-Инвестиций;
ведёт учёт портфеля по FIFO;
рассчитывает налоги;
анализирует портфель;
контролирует соответствие инвестиционной стратегии;
предлагает рекомендации по покупке активов;
полностью работает на русском языке.

Проект не является простой выгрузкой данных из API. Это полноценная система управления инвестициями.

Моё дополнение для Codex

Я бы попросил Codex не только писать код, но и проводить архитектурную ревизию каждого нового модуля перед реализацией. Если он увидит потенциальную проблему (например, нарушение принципа разделения ответственности, зависимость от порядка столбцов или дублирование логики), лучше исправить её до написания кода, чем после. Это поможет сохранить архитектуру проекта чистой и избежать накопления технического долга.
