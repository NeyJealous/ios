ТЗ ДЛЯ CODEX
Investment Operating System v2.2 — Расширение архитектуры счетов и резерва

Этот документ дополняет основное ТЗ v2.2 "Stabilization, Synchronization & Investment Universe".

1. РЕЗЕРВ

Резерв — отдельная функция портфеля.

Резерв = свободные деньги + стоимость инструментов, отмеченных как "Инструмент резерва".

Основной инструмент хранения резерва — фонд денежного рынка (настраивается пользователем).

Настройки стратегии:
- основной инструмент резерва;
- минимальная доля резерва;
- целевая доля резерва;
- максимальная доля резерва;
- предпочитаемый счет хранения.

Если резерв ниже цели, Советник должен:
- определить недостающую сумму;
- рассчитать количество бумаг и лотов фонда денежного рынка;
- учитывать размер лота;
- показать остаток денежных средств после покупки.

Если суммы недостаточно для покупки минимального лота — вывести понятное сообщение.

План сделок должен формировать отдельную рекомендацию:
«Купить фонд денежного рынка для восстановления резерва».

2. МНОГОСЧЕТНАЯ АРХИТЕКТУРА

Каждый счет имеет:
- ID;
- название;
- брокера;
- статус активности;
- включать в общий портфель (Да/Нет);
- использовать для хранения резерва (Да/Нет);
- роль;
- назначенную стратегию;
- комментарий.

Роли:
- Основной;
- ИИС;
- Облигационный;
- Резервный;
- Экспериментальный;
- Не учитывать.

Все связи строятся только по ID счета.

3. СТРАТЕГИИ

Все параметры стратегии хранятся только в листе "Стратегии".

В нем находятся:
- доля акций;
- доля облигаций;
- доля фондов;
- доля резерва;
- лимиты;
- правила покупок;
- правила продаж;
- адаптация к рынку;
- настройки ребалансировки.

Это единственный источник истины.

4. СТРАТЕГИИ СЧЕТОВ

Лист "Стратегии счетов" не хранит доли.

Он содержит:
- ID счета;
- название счета;
- выбранную стратегию;
- использовать индивидуальные настройки (Да/Нет);
- использовать резерв;
- роль счета;
- комментарий.

Если индивидуальные настройки отключены:
все параметры автоматически наследуются из выбранной стратегии.

Если включены:
разрешается переопределить:
- долю акций;
- долю облигаций;
- долю фондов;
- долю резерва;
- ограничения.

По умолчанию индивидуальные настройки выключены.

5. ОБЩИЙ ПОРТФЕЛЬ

Система должна поддерживать:
- общий портфель;
- портфель каждого счета;
- рекомендации по каждому счету;
- общий советник;
- общий план сделок.

Счета, исключенные из общего портфеля, не участвуют в общих KPI, Portfolio Health и ребалансировке, но доступны для отдельного анализа.

6. СОВЕТНИК

Советник должен:
- показывать рекомендации по всему портфелю;
- показывать рекомендации по каждому счету;
- отображать состояние резерва;
- рекомендовать покупку фонда денежного рынка;
- рассчитывать количество бумаг и лотов;
- учитывать минимальный размер лота.

7. ПРИНЦИП ЕДИНСТВЕННОГО ИСТОЧНИКА ИСТИНЫ

Стратегии — единственный источник параметров стратегии.
Стратегии счетов — только связь счета со стратегией.
Счета — информация о счетах.
Портфель — текущее состояние.
Решения — итог работы движка.

Параметры стратегии запрещено дублировать между листами.
