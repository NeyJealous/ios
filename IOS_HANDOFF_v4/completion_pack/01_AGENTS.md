# AGENTS.md — правила для Codex в проекте IOS

## Источники истины

1. Утверждённая Master Specification и Correction Memo.
2. Рабочий Apps Script проект.
3. Рабочая Google Sheets.
4. Тесты и журнал выполнения.
5. Локальный репозиторий.

При расхождении не угадывай — зафиксируй конфликт.

## Запреты

- Не удалять `.gs`.
- Не удалять `.js` до сравнения и подтверждения.
- Не выполнять `clasp push --force` без backup и `clasp status`.
- Не менять инвестиционную стратегию без требования.
- Не формировать рекомендации вне Decision Engine.
- Не выводить и не изменять секреты без явного указания.
- Не хранить токены в коде, таблице, Git или отчётах.
- Не использовать названия счетов как ключи.
- Не добавлять автоторговлю, One Click Execution или отдельное приложение.
- Не считать наличие файла доказательством работоспособности.
- Не считать наличие теста доказательством прохождения.

## Реализация

- Один модуль — одна ответственность.
- Машинные entry points — top-level wrapper-функции.
- Внутренняя логика — в namespace.
- Чтение и запись листов — пакетно.
- Не использовать getRange/setValue/appendRow/UrlFetchApp.fetch в больших циклах.
- История обновляется инкрементально.
- Синхронизация использует LockService.
- Каждый запуск журналирует mode, runId, длительность, строки, API-запросы и ошибки.
- Remote entry points возвращают только JSON-safe типы.
- Не возвращать Sheet, Range, Date, Blob, Iterator или service object.

## Цикл задачи

1. Зафиксировать baseline.
2. Проанализировать код и требования.
3. Предложить минимальный план.
4. Внести минимальный diff.
5. Запустить локальные проверки.
6. Показать `clasp status`.
7. Выполнить push после разрешения.
8. Запустить удалённые тесты.
9. Проверить результат в таблице через MCP/API.
10. Обновить документацию.
11. Отчитаться.

## Отчёт

- найдено;
- изменено;
- файлы;
- выполненные команды;
- тесты;
- проверка в таблице;
- оставшиеся риски;
- можно ли переходить дальше: Да/Нет.


## Environment gate

После чистой установки Windows перед любой работой с кодом:

1. прочитать `00A_WINDOWS_CLEAN_INSTALL_BOOTSTRAP.md`;
2. выполнить `tools/Check-IOSDevEnvironment.ps1`;
3. создать environment report;
4. не выполнять `clasp pull/push/run-function`, пока `ReadyForCodex00` не равно `true`;
5. не устанавливать программы без явного подтверждения пользователя;
6. не помещать OAuth credentials, `.clasprc.json`, токены и `.env` в репозиторий.


## Browser runtime fallback

Если CODEX-00 не завершён из-за OAuth, API Executable, Cloud Project или отсутствия MCP, не импровизируй.

1. Зафиксируй классификацию ошибки.
2. Получи разрешение пользователя на CODEX-00B.
3. Прочитай `CODEX-00B_BROWSER_RUNTIME_FALLBACK.md`.
4. Используй браузер только для запуска, авторизации, просмотра Executions и проверки таблицы.
5. Основные изменения кода выполняй в локальном Git.
6. Каждый browser-run подтверждай Run ID, записью в «Диагностика» и проверкой целевого листа.
7. Не объявляй автоматический runtime настроенным, если использовался только браузер.
