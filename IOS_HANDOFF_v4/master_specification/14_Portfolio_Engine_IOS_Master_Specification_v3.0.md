# Investment Operating System (IOS)

# Master Specification v3.0

# 14 --- Portfolio Engine

**Статус:** Каноническая спецификация Portfolio Engine

## Назначение

Portfolio Engine отвечает за анализ текущего состояния портфеля,
сравнение его с целевой стратегией и подготовку данных для Decision
Engine.

Portfolio Engine не принимает окончательных инвестиционных решений ---
он оценивает состояние портфеля.

------------------------------------------------------------------------

# Основные задачи

-   анализ структуры портфеля;
-   расчет фактических долей активов;
-   сравнение с целевой стратегией;
-   расчет отклонений;
-   определение необходимости ребалансировки;
-   расчет Portfolio Health;
-   подготовка данных для Advisor и Trade Plan.

------------------------------------------------------------------------

# Входные данные

Используются:

-   Портфель;
-   Сделки;
-   Счета;
-   Стратегии;
-   Стратегии счетов;
-   Решения;
-   Investment Universe;
-   Bond Engine;
-   Company Rating;
-   Reserve Engine;
-   Market Regime.

------------------------------------------------------------------------

# Поддержка нескольких счетов

Portfolio Engine обязан одновременно рассчитывать:

-   каждый счет отдельно;
-   группы счетов (при необходимости);
-   общий портфель.

Каждый счет может:

-   использовать собственную стратегию;
-   быть исключен из общего портфеля;
-   иметь собственную роль;
-   использоваться для хранения резерва.

Связь выполняется только по Account ID.

------------------------------------------------------------------------

# Portfolio Health

Portfolio Health рассчитывается по нескольким независимым направлениям:

-   соответствие стратегии;
-   диверсификация;
-   концентрация;
-   качество облигаций;
-   качество акций;
-   состояние резерва;
-   купонный поток;
-   денежный поток;
-   уровень риска;
-   ликвидность.

Итоговая оценка должна сопровождаться объяснением.

------------------------------------------------------------------------

# Анализ структуры

Оцениваются:

-   доля акций;
-   доля облигаций;
-   доля фондов;
-   доля резерва;
-   распределение по секторам;
-   распределение по эмитентам;
-   распределение по счетам;
-   распределение по стратегиям.

------------------------------------------------------------------------

# Ребалансировка

Portfolio Engine определяет:

-   требуется ли ребалансировка;
-   какие активы отклоняются от цели;
-   допустимые диапазоны;
-   приоритет корректировок.

Не допускается создание рекомендаций с нулевой суммой.

------------------------------------------------------------------------

# Концентрация

Контролируется:

-   максимальная доля одного эмитента;
-   максимальная доля сектора;
-   максимальная доля инструмента;
-   концентрация купонных выплат;
-   концентрация дивидендного потока.

------------------------------------------------------------------------

# Денежный поток

Portfolio Engine анализирует:

-   дивиденды;
-   купоны;
-   распределение выплат по месяцам;
-   качество денежного потока.

Информация передается в Coupon Ladder и Advisor.

------------------------------------------------------------------------

# Резерв

Использует данные Reserve Engine.

Контролирует:

-   фактический резерв;
-   целевой резерв;
-   необходимость восстановления.

------------------------------------------------------------------------

# Выходные данные

Формируются:

-   Portfolio Health;
-   структура портфеля;
-   отклонения;
-   данные для ребалансировки;
-   данные для Decision Engine;
-   данные для Advisor;
-   данные для Главной.

------------------------------------------------------------------------

# Definition of Done

Portfolio Engine считается завершенным, если:

-   поддерживает многосчетную архитектуру;
-   использует только источники истины;
-   не зависит от пользовательских листов;
-   корректно рассчитывает Portfolio Health;
-   полностью документирован.
