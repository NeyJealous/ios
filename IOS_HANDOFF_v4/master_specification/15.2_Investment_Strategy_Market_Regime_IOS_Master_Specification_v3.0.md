# Investment Operating System (IOS)

# Master Specification v3.0

# 15.2 --- Investment Strategy

## Анализ рыночного режима

**Статус:** Каноническая спецификация анализа рыночного режима

## Назначение

Модуль определяет текущую фазу рынка и корректирует приоритеты
инвестиционной стратегии. Он не запрещает долгосрочные инвестиции, а
изменяет очередность рекомендаций.

------------------------------------------------------------------------

# Принципы

-   Долгосрочная стратегия не меняется из-за краткосрочных колебаний.
-   Рыночный режим влияет на темп покупок, но не отменяет их.
-   Любое изменение режима должно быть объяснимо.

------------------------------------------------------------------------

# Используемые источники

-   Ключевая ставка Банка России.
-   Инфляция.
-   Доходности ОФЗ.
-   Индекс возможностей.
-   Portfolio Health.
-   Состояние резерва.
-   Доля свободных средств.

------------------------------------------------------------------------

# Поддерживаемые режимы

## Накопление

Рынок дорогой, возможностей немного.

Приоритет: - пополнение резерва; - покупка только сильнейших активов.

------------------------------------------------------------------------

## Нормальный режим

Базовое распределение активов.

Покупки выполняются согласно целевым долям стратегии.

------------------------------------------------------------------------

## Повышенные возможности

Рынок предоставляет большое количество привлекательных активов.

Допускается: - ускоренное инвестирование; - использование части резерва
в пределах стратегии.

------------------------------------------------------------------------

## Стрессовый режим

Высокая волатильность или кризис.

Приоритет: - контроль риска; - сохранение ликвидности; - покупка только
высококачественных активов.

------------------------------------------------------------------------

# Индекс возможностей

Индекс возможностей рассчитывается отдельным модулем.

Decision Engine использует его как один из факторов, но не как
единственную причину покупки.

------------------------------------------------------------------------

# Влияние ключевой ставки

Повышение ставки увеличивает привлекательность:

-   фонда денежного рынка;
-   новых выпусков облигаций;
-   коротких облигаций.

Снижение ставки постепенно повышает привлекательность:

-   акций роста;
-   длинных ОФЗ;
-   долгосрочных облигаций.

------------------------------------------------------------------------

# Влияние инфляции

Высокая инфляция повышает требования к реальной доходности инвестиций.

Стратегия обязана учитывать риск потери покупательной способности
капитала.

------------------------------------------------------------------------

# Влияние на другие модули

Режим рынка влияет на:

-   Bond Engine;
-   Company Rating;
-   Reserve Engine;
-   Portfolio Engine;
-   Decision Engine.

Ни один модуль не должен игнорировать Market Regime.

------------------------------------------------------------------------

# Объяснимость

При изменении режима пользователю отображается:

-   новый режим;
-   основные причины изменения;
-   влияние на рекомендации.

------------------------------------------------------------------------

# Definition of Done

Модуль считается завершенным, если:

-   автоматически определяет режим;
-   использует документированные правила;
-   влияет на рекомендации через Decision Engine;
-   полностью объясняет изменение режима.
