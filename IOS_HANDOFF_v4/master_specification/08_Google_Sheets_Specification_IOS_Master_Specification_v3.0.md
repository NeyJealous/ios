# Investment Operating System (IOS)

# Master Specification v3.0

# 08 --- Google Sheets Specification

**Статус:** Каноническая спецификация структуры Google Sheets

## Назначение

Google Sheets является пользовательским интерфейсом Investment Operating
System.

Листы не являются ядром бизнес-логики. Они служат: - хранилищем
данных; - промежуточным кэшем; - пользовательским интерфейсом; -
источником ручных настроек.

------------------------------------------------------------------------

# Общие правила

Каждый лист обязан иметь:

-   владельца (Apps Script модуль);
-   источник истины;
-   описание назначения;
-   режим обновления;
-   правила чтения;
-   правила записи.

Запрещается: - выполнять сложные расчеты в пользовательских формулах; -
использовать визуальные листы как источник бизнес-логики; - вручную
изменять автоматически рассчитываемые поля.

------------------------------------------------------------------------

# Классификация листов

## 1. Системные

Примеры: - Настройки - Конфигурация - Счета - Стратегии - Стратегии
счетов

Редактируются пользователем.

------------------------------------------------------------------------

## 2. Источники данных

-   Сделки
-   Портфель
-   Справочник
-   Данные источников

Заполняются автоматически.

Являются источниками истины.

------------------------------------------------------------------------

## 3. Аналитические

-   Инвестиционная вселенная
-   Факты
-   Признаки
-   Оценки
-   Решения
-   Bond Engine
-   Company Rating
-   Portfolio Health

Формируются автоматически.

Пользователь не редактирует.

------------------------------------------------------------------------

## 4. Пользовательские

-   Главная
-   Советник
-   План сделок

Отображают результаты анализа.

Не содержат бизнес-логики.

------------------------------------------------------------------------

# Спецификация ключевых листов

## Сделки

Назначение: История всех операций.

Источник: T-Invest.

Режим: Инкрементальная загрузка.

Запись: Только BatchSync.

Редактирование: Запрещено.

------------------------------------------------------------------------

## Портфель

Назначение: Текущее состояние позиций.

Источник: T-Invest.

Используют: - Portfolio Engine - Advisor - Rebalance - Portfolio Health

------------------------------------------------------------------------

## Справочник

Назначение: Полный каталог инструментов.

Не фильтрует бумаги.

Не содержит решений.

------------------------------------------------------------------------

## Инвестиционная вселенная

Назначение: Рабочий набор инструментов.

Содержит:

-   статус доступности;
-   категорию;
-   признаки отбора;
-   возможность покупки;
-   статус исключения.

Любые изменения журналируются.

------------------------------------------------------------------------

## Факты

Только объективные показатели.

Запрещено хранить рекомендации.

------------------------------------------------------------------------

## Признаки

Производные характеристики.

Например:

-   высокая доходность;
-   защитный актив;
-   подходит резерву;
-   купон закрывает месяц.

------------------------------------------------------------------------

## Оценки

Все скоринговые модели.

Каждая оценка сопровождается объяснением.

------------------------------------------------------------------------

## Решения

Единственный источник рекомендаций.

Никакой другой лист не имеет права самостоятельно рекомендовать покупку.

------------------------------------------------------------------------

## Советник

Показывает:

-   рекомендации;
-   причины;
-   объяснения;
-   уверенность;
-   сумму;
-   количество;
-   счет;
-   стратегию.

Не содержит вычислений.

------------------------------------------------------------------------

## План сделок

Формируется только на основании листа "Решения".

------------------------------------------------------------------------

## Главная

Показывает итоговое состояние системы.

Использует только готовые данные.

------------------------------------------------------------------------

# Технические требования

Во всех пользовательских листах запрещено отображать:

-   FIGI;
-   UID;
-   внутренние ID;
-   JSON;
-   служебные признаки.

Все подписи --- только на русском языке.

------------------------------------------------------------------------

# Синхронизация листов

Каждый лист относится к одному из режимов:

-   Быстрая синхронизация;
-   Полная синхронизация;
-   Пересчет рекомендаций.

Это должно быть явно указано в его описании.

------------------------------------------------------------------------

# Definition of Done

Структура Google Sheets считается завершенной, если:

-   отсутствуют циклические зависимости;
-   каждый лист имеет владельца;
-   пользовательские листы не содержат бизнес-логики;
-   источники истины определены;
-   структура описана в Data Dictionary.
