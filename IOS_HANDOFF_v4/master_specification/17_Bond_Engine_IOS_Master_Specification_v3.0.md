# Investment Operating System (IOS)

# Master Specification v3.0

# 17 --- Bond Engine

**Статус:** Каноническая спецификация Bond Engine

## Назначение

Bond Engine является специализированным аналитическим модулем,
отвечающим за комплексную оценку облигаций.

Он не формирует инвестиционные рекомендации самостоятельно. Его задача
--- предоставить объективную оценку качества выпуска для Decision
Engine.

------------------------------------------------------------------------

# Основные цели

-   выбирать лучшие выпуски облигаций;
-   оценивать риск;
-   учитывать влияние ключевой ставки;
-   поддерживать купонную лестницу;
-   обеспечивать объяснимость каждой оценки.

------------------------------------------------------------------------

# Поддерживаемые типы

-   ОФЗ с постоянным купоном;
-   ОФЗ-ПК (флоатеры);
-   корпоративные облигации;
-   субфедеральные облигации (при поддержке стратегии).

------------------------------------------------------------------------

# Обязательные параметры анализа

Для каждого выпуска рассчитываются:

-   доходность к погашению (YTM);
-   текущая доходность;
-   цена;
-   НКД;
-   дюрация;
-   дата погашения;
-   размер купона;
-   периодичность выплат;
-   кредитный рейтинг;
-   ликвидность;
-   оферта;
-   амортизация;
-   эффективная доходность после комиссий и налогов (при наличии
    данных).

------------------------------------------------------------------------

# Система оценки

Оценка формируется по независимым блокам:

1.  Надежность эмитента.
2.  Доходность.
3.  Процентный риск.
4.  Ликвидность.
5.  Структура выпуска.
6.  Купонная привлекательность.
7.  Соответствие стратегии.
8.  Вклад в купонную лестницу.

Каждый блок имеет собственный вес.

------------------------------------------------------------------------

# Правила выбора

При сравнении выпусков приоритет следующий:

1.  Соответствие стратегии.
2.  Надежность.
3.  Полнота данных.
4.  Доходность.
5.  Дюрация.
6.  Ликвидность.
7.  Купонная лестница.

Высокая доходность не компенсирует высокий риск.

------------------------------------------------------------------------

# Влияние ключевой ставки

Высокая ставка:

-   повышает привлекательность новых выпусков;
-   увеличивает роль флоатеров;
-   снижает привлекательность длинной фиксированной дюрации.

Снижение ставки:

-   повышает привлекательность длинных ОФЗ;
-   увеличивает потенциал роста цены облигаций.

------------------------------------------------------------------------

# Купонная лестница

Bond Engine передает в Coupon Ladder:

-   месяцы выплат;
-   ожидаемые суммы;
-   прогноз денежного потока;
-   влияние покупки выпуска на календарь.

------------------------------------------------------------------------

# Недостаток данных

Если отсутствуют критически важные параметры:

-   рейтинг не рассчитывается;
-   статус: "Недостаточно данных".

Покупка такого выпуска запрещена.

------------------------------------------------------------------------

# Выходные данные

Для каждого выпуска формируются:

-   итоговый рейтинг;
-   оценки по каждому блоку;
-   причины;
-   сильные стороны;
-   слабые стороны;
-   уровень уверенности;
-   вклад в купонную лестницу.

------------------------------------------------------------------------

# Использование

Bond Engine используется:

-   Decision Engine;
-   Portfolio Engine;
-   Reserve Engine;
-   Coupon Ladder;
-   Advisor.

------------------------------------------------------------------------

# Definition of Done

Bond Engine считается завершенным, если:

-   оценивает все поддерживаемые типы облигаций;
-   полностью объясняет итоговую оценку;
-   интегрирован с Coupon Ladder;
-   учитывает ключевую ставку;
-   использует только документированные правила.
