# Investment Operating System (IOS)

# Master Specification v3.0

# 10 --- Investment Universe

**Статус:** Каноническая спецификация инвестиционной вселенной

## Назначение

Investment Universe является рабочим набором инструментов, из которого
Investment Operating System может формировать рекомендации.

Справочник содержит **все** известные инструменты. Investment Universe
содержит **только те**, которые могут участвовать в инвестиционной
логике.

------------------------------------------------------------------------

# Цели

-   исключить использование полного Справочника в аналитике;
-   обеспечить единый набор инструментов для всех модулей;
-   сохранить историю изменений состава Вселенной;
-   обеспечить воспроизводимость рекомендаций.

------------------------------------------------------------------------

# Источник данных

    T-Invest
          │
          ▼
    Справочник
          │
          ▼
    Investment Universe

Investment Universe никогда не обращается напрямую к API.

------------------------------------------------------------------------

# Поддерживаемые классы активов

На текущем этапе:

-   Акции;
-   Облигации;
-   Биржевые фонды.

Другие классы активов допускаются только после обновления Master
Specification.

------------------------------------------------------------------------

# Правила включения

Инструмент включается, если одновременно выполняются условия:

-   доступен неквалифицированному инвестору;
-   торгуется на поддерживаемой площадке;
-   относится к поддерживаемому классу активов;
-   не заблокирован пользователем;
-   не находится в списке исключений стратегии.

------------------------------------------------------------------------

# Правила исключения

Инструмент НЕ исключается только потому, что:

-   выходной день;
-   вечерняя сессия закрыта;
-   временно отсутствуют сделки.

Исключение возможно только при наличии объективной причины:

-   делистинг;
-   прекращение обращения;
-   недоступность для выбранной стратегии;
-   пользовательское исключение.

------------------------------------------------------------------------

# Статусы

Каждый инструмент имеет независимые признаки:

-   Есть в Справочнике;
-   Есть во Вселенной;
-   Доступен стратегии;
-   Можно купить сейчас;
-   Находится в портфеле;
-   Используется как резерв;
-   Используется в купонной лестнице.

Эти признаки не должны смешиваться.

------------------------------------------------------------------------

# Дополнительные атрибуты

Для каждого инструмента рекомендуется хранить:

-   класс актива;
-   сектор;
-   страна;
-   валюта;
-   ликвидность;
-   уровень риска;
-   стратегия использования;
-   приоритет анализа.

------------------------------------------------------------------------

# Взаимодействие с другими модулями

Используют:

-   Bond Engine;
-   Company Rating;
-   Decision Engine;
-   Advisor;
-   Portfolio Engine;
-   Reserve Engine.

Запрещено обращаться напрямую к Справочнику, если требуется только
рабочий набор инструментов.

------------------------------------------------------------------------

# Universe Diff

Любое изменение состава Investment Universe фиксируется.

Для каждого изменения сохраняются:

-   дата;
-   инструмент;
-   тип изменения;
-   причина;
-   источник;
-   модуль.

------------------------------------------------------------------------

# Definition of Done

Investment Universe считается реализованной, если:

-   отделена от Справочника;
-   имеет собственные правила включения и исключения;
-   используется всеми аналитическими модулями;
-   поддерживает журнал изменений;
-   документирована.
