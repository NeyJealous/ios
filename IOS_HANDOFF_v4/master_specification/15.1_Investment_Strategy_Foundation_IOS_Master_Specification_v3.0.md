# Investment Operating System (IOS)

# Master Specification v3.0

# 15.1 --- Investment Strategy

## Часть 1. Философия и базовые принципы

**Статус:** Каноническая инвестиционная стратегия IOS

## Назначение

Investment Strategy определяет правила принятия всех инвестиционных
решений в системе.

Никакой модуль не имеет права отклоняться от данной стратегии без
внесения изменений в Master Specification.

------------------------------------------------------------------------

# Главная цель

Создать долгосрочный инвестиционный портфель, который:

-   увеличивает капитал;
-   формирует стабильный денежный поток;
-   требует минимального ручного сопровождения;
-   адаптируется к изменению рыночной среды;
-   принимает объяснимые решения.

------------------------------------------------------------------------

# Горизонт инвестирования

Базовый горизонт:

-   10+ лет.

Система ориентирована на долгосрочное накопление капитала.

Краткосрочные рыночные колебания сами по себе не являются основанием для
изменения стратегии.

------------------------------------------------------------------------

# Поддерживаемые классы активов

На текущем этапе:

-   Акции;
-   Облигации;
-   Биржевые фонды.

Другие классы активов будут добавляться только через обновление Master
Specification.

------------------------------------------------------------------------

# Базовые принципы

1.  Качество важнее доходности.
2.  Диверсификация важнее концентрации.
3.  Риск контролируется заранее.
4.  Решения принимаются на основании данных.
5.  Любая рекомендация должна быть объяснима.
6.  При недостатке данных система выбирает статус "Недостаточно данных".

------------------------------------------------------------------------

# Источники принятия решений

Decision Engine обязан учитывать:

-   Strategy;
-   Market Regime;
-   Bond Engine;
-   Company Rating;
-   Portfolio Engine;
-   Reserve Engine;
-   Coupon Ladder;
-   Investment Universe.

Ни один фактор не используется изолированно.

------------------------------------------------------------------------

# Цели по денежному потоку

IOS стремится обеспечить:

-   регулярные дивиденды;
-   регулярные купонные выплаты;
-   максимально равномерное распределение купонов по месяцам;
-   восстановление резерва до целевого уровня.

Свободные денежные средства рассматриваются как временное состояние.

Основной резерв хранится в фонде денежного рынка.

------------------------------------------------------------------------

# Работа с несколькими счетами

Каждый счет может:

-   иметь собственную стратегию;
-   иметь собственную роль;
-   участвовать или не участвовать в общем портфеле;
-   использоваться для хранения резерва.

Общий портфель рассчитывается только по счетам, отмеченным как активные
для агрегирования.

------------------------------------------------------------------------

# Приоритет безопасности

При выборе между более высокой потенциальной доходностью и более низким
риском предпочтение отдается варианту, соответствующему стратегии и
уровню риска пользователя.

------------------------------------------------------------------------

# Принцип развития стратегии

Новые правила могут добавляться только при соблюдении условий:

-   не нарушают Конституцию проекта;
-   совместимы с существующей архитектурой;
-   документированы;
-   тестируемы;
-   объяснимы пользователю.
