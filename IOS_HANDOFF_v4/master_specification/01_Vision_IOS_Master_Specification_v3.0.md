# Investment Operating System (IOS)

# Master Specification v3.0

# 01 --- Vision

Статус: Living Engineering Documentation

------------------------------------------------------------------------

# Миссия

Создать лучшую персональную инвестиционную систему для долгосрочного
инвестора, которая помогает принимать последовательные, объяснимые и
обоснованные инвестиционные решения.

IOS не заменяет инвестора. IOS предоставляет данные, анализ и
рекомендации, оставляя окончательное решение пользователю.

------------------------------------------------------------------------

# Цели проекта

## Краткосрочные

-   стабилизировать архитектуру;
-   создать единый источник истины;
-   внедрить Investment Universe;
-   реализовать трехрежимную синхронизацию;
-   минимизировать API-запросы;
-   обеспечить высокую производительность Apps Script.

## Среднесрочные

-   полностью автоматизировать анализ портфеля;
-   автоматически оценивать акции, облигации и фонды;
-   поддерживать несколько счетов и стратегий;
-   построить купонную лестницу;
-   управлять резервом через фонд денежного рынка.

## Долгосрочные

-   превратить IOS в полностью документированную инженерную систему;
-   обеспечить возможность сопровождения любым разработчиком без потери
    знаний;
-   создать надежную платформу для многолетнего использования.

------------------------------------------------------------------------

# Основные принципы

1.  Простота важнее количества функций.
2.  Архитектура важнее скорости разработки.
3.  Каждый показатель имеет один источник истины.
4.  Любая рекомендация должна быть объяснима.
5.  Пользователь никогда не должен видеть внутреннюю техническую
    реализацию.
6.  История данных никогда не уничтожается без явного решения
    пользователя.
7.  Производительность является частью функциональности.
8.  Документация развивается вместе с кодом.

------------------------------------------------------------------------

# Что такое Investment Operating System

IOS состоит из трех уровней:

## Данные

Источники → Справочник → Инвестиционная вселенная → Факты.

## Аналитика

Признаки → Оценки → Решения.

## Представление

Главная → Советник → План сделок → Отчеты.

Каждый уровень зависит только от предыдущего.

------------------------------------------------------------------------

# Целевая модель инвестирования

Основные классы активов:

-   акции;
-   облигации;
-   фонды.

Поддерживается:

-   несколько брокерских счетов;
-   несколько стратегий;
-   общий портфель;
-   индивидуальные портфели;
-   резерв;
-   купонная лестница;
-   ребалансировка.

------------------------------------------------------------------------

# Основные требования

Система должна:

-   работать быстро;
-   использовать пакетные операции;
-   минимизировать обращения к API;
-   хранить историю;
-   автоматически документировать изменения архитектуры;
-   быть масштабируемой.

------------------------------------------------------------------------

# Что не входит в цели

-   высокочастотная торговля;
-   непрозрачные рекомендации;
-   сложный пользовательский интерфейс;
-   ручное дублирование данных;
-   зависимость бизнес-логики от визуальных листов.
