# Investment Operating System (IOS)

# Master Specification v3.0

# 11 --- Universe Diff

**Статус:** Спецификация контроля изменений инвестиционной вселенной

## Назначение

Universe Diff отслеживает все изменения состава Investment Universe и
объясняет их причины.

Цель --- сделать состав инвестиционной вселенной полностью прозрачным и
воспроизводимым.

------------------------------------------------------------------------

# Основные задачи

Universe Diff должен автоматически обнаруживать:

-   новые инструменты;
-   исключенные инструменты;
-   изменение доступности для неквалифицированных инвесторов;
-   смену класса актива;
-   изменение торгового статуса;
-   изменение стратегии использования.

------------------------------------------------------------------------

# Источники данных

Источником сравнения являются:

-   Справочник;
-   Investment Universe;
-   предыдущая сохраненная версия Universe.

API напрямую не используется.

------------------------------------------------------------------------

# Типы событий

## Добавление

Причины:

-   появился новый выпуск;
-   бумага стала доступна;
-   удовлетворяет правилам стратегии.

------------------------------------------------------------------------

## Исключение

Причины:

-   делистинг;
-   прекращение обращения;
-   ручное исключение;
-   изменение правил стратегии.

------------------------------------------------------------------------

## Изменение

Например:

-   изменился сектор;
-   изменилась ликвидность;
-   изменился статус покупки;
-   изменился кредитный рейтинг;
-   изменилась принадлежность к резерву.

------------------------------------------------------------------------

# Журнал изменений

Каждая запись должна содержать:

-   дату;
-   тикер;
-   название;
-   тип изменения;
-   старое значение;
-   новое значение;
-   причину;
-   источник;
-   модуль, выполнивший изменение.

Журнал не очищается автоматически.

------------------------------------------------------------------------

# Использование

Universe Diff используется:

-   Bond Engine;
-   Company Rating;
-   Decision Engine;
-   Advisor;
-   Diagnostics.

------------------------------------------------------------------------

# Уведомления

При значимых изменениях система должна уведомлять пользователя.

Примеры:

-   Добавлено 12 новых ОФЗ.
-   Появился новый фонд денежного рынка.
-   Исключено 3 делистинговых инструмента.
-   Изменен статус доступности выпуска.

Сообщения должны быть понятными и полностью на русском языке.

------------------------------------------------------------------------

# Ограничения

Запрещено:

-   удалять историю изменений;
-   изменять прошлые записи;
-   скрывать причины изменений.

------------------------------------------------------------------------

# Definition of Done

Universe Diff считается завершенным, если:

-   автоматически обнаруживает изменения;
-   журналирует все события;
-   предоставляет данные другим модулям;
-   не требует ручного сопровождения;
-   полностью документирован.
