# Investment Operating System (IOS)

# Master Specification v3.0

# 15.6 --- Coupon Ladder

**Статус:** Каноническая спецификация купонной лестницы

## Назначение

Coupon Ladder отвечает за построение максимально равномерного купонного
денежного потока.

Цель системы --- не максимальное количество купонов, а их равномерное
распределение по календарным месяцам.

------------------------------------------------------------------------

# Основные принципы

1.  Купонный поток должен быть максимально равномерным.
2.  Качество облигации всегда важнее календаря выплат.
3.  Купонная лестница является частью общей инвестиционной стратегии.
4.  Решения принимаются совместно с Bond Engine и Decision Engine.

------------------------------------------------------------------------

# Источники данных

Используются:

-   Портфель;
-   Сделки;
-   Bond Engine;
-   Investment Universe;
-   Strategy;
-   Reserve Engine.

------------------------------------------------------------------------

# Купонный календарь

Для каждой облигации сохраняются:

-   дата выплаты;
-   месяц выплаты;
-   размер купона;
-   количество выплат в год;
-   ожидаемый купон по текущей позиции.

Формируется агрегированный календарь:

  Месяц   Плановый купон   Целевой купон   Отклонение
  ------- ---------------- --------------- ------------

------------------------------------------------------------------------

# Анализ покрытия

Для каждого месяца определяется:

-   закрыт полностью;
-   закрыт частично;
-   отсутствуют выплаты.

Месяцы без выплат получают повышенный приоритет при подборе новых
облигаций.

------------------------------------------------------------------------

# Правила выбора

Если несколько выпусков имеют близкие характеристики, предпочтение
получает выпуск, который:

1.  закрывает пустой месяц;
2.  выравнивает денежный поток;
3.  не ухудшает качество портфеля.

Календарь не может быть единственной причиной покупки.

------------------------------------------------------------------------

# Ограничения

Запрещено:

-   покупать слабую облигацию ради календаря;
-   нарушать стратегию счета;
-   превышать лимиты концентрации;
-   ухудшать Portfolio Health.

------------------------------------------------------------------------

# Выходные данные

Coupon Ladder формирует:

-   календарь выплат;
-   месяцы с недостатком купонов;
-   прогноз денежного потока;
-   рекомендации по закрытию пустых месяцев;
-   влияние покупки на календарь.

------------------------------------------------------------------------

# Взаимодействие

Используется:

-   Bond Engine;
-   Portfolio Engine;
-   Advisor;
-   Decision Engine.

Advisor обязан объяснять, если рекомендация связана с выравниванием
купонного календаря.

------------------------------------------------------------------------

# Будущее развитие

Планируется добавить:

-   прогноз купонов на несколько лет;
-   учет налогов;
-   прогноз реального денежного потока после НДФЛ;
-   моделирование альтернативных покупок.

------------------------------------------------------------------------

# Definition of Done

Coupon Ladder считается завершенной, если:

-   автоматически строит календарь;
-   выявляет пустые месяцы;
-   рассчитывает ожидаемый поток;
-   влияет на Decision Engine;
-   полностью документирована.
