# Назначение

Investment Operating System (IOS) --- это инженерная платформа
управления инвестиционным портфелем, построенная на Google Sheets + Apps
Script с модульной архитектурой, единым источником истины и полностью
документированным процессом разработки.

Проект предназначен для:

-   управления несколькими инвестиционными счетами;
-   поддержки различных инвестиционных стратегий;
-   автоматического анализа акций, облигаций и фондов;
-   формирования рекомендаций;
-   контроля здоровья портфеля;
-   автоматической синхронизации данных;
-   масштабируемого развития без накопления технического долга.

------------------------------------------------------------------------

# Главные принципы

1.  Документация имеет приоритет над реализацией.
2.  Любое архитектурное изменение сначала отражается в Master
    Specification.
3.  Код не должен противоречить Конституции проекта.
4.  Один источник истины для каждого типа данных.
5.  Пользователь работает только с русским интерфейсом.
6.  Никаких технических идентификаторов в пользовательских листах.
7.  Любая новая функция должна упрощать систему, а не усложнять её.
