# Investment Operating System (IOS)

# Master Specification v3.0

# 12 --- Decision Engine

**Статус:** Каноническая спецификация Decision Engine

## Назначение

Decision Engine является единственным модулем, имеющим право формировать
инвестиционные рекомендации.

Ни один другой модуль не должен самостоятельно рекомендовать покупку,
продажу или удержание инструмента.

# Основная задача

Decision Engine объединяет результаты работы специализированных модулей
и формирует единое объяснимое решение.

------------------------------------------------------------------------

# Используемые источники

Обязательно учитываются:

-   Bond Engine;
-   Company Rating;
-   Portfolio Engine;
-   Reserve Engine;
-   Market Regime;
-   Strategy;
-   Investment Universe.

При необходимости могут использоваться дополнительные аналитические
модули.

------------------------------------------------------------------------

# Типы решений

Поддерживаются следующие решения:

-   Купить;
-   Докупить;
-   Держать;
-   Сократить;
-   Продать;
-   Восстановить резерв;
-   Купить для купонной лестницы;
-   Недостаточно данных.

------------------------------------------------------------------------

# Обязательные проверки

Перед выдачей рекомендации необходимо проверить:

-   инструмент присутствует в Investment Universe;
-   стратегия допускает покупку;
-   данных достаточно;
-   инструмент не исключен пользователем;
-   отсутствуют критические риски.

При нарушении любого условия решение "Купить" запрещено.

------------------------------------------------------------------------

# Приоритет факторов

По умолчанию применяется следующий порядок:

1.  Ограничения стратегии.
2.  Критические риски.
3.  Достаточность данных.
4.  Bond Engine / Company Rating.
5.  Portfolio Engine.
6.  Reserve Engine.
7.  Coupon Ladder.
8.  Рыночный режим.

------------------------------------------------------------------------

# Конфликты

При конфликте между модулями используется более консервативное решение.

Примеры:

Bond Engine → Купить

Strategy → Запрещено

Итог:

Запрет покупки.

------------------------------------------------------------------------

Portfolio Engine → Докупить

Reserve Engine → Восстановить резерв

Итог:

Сначала восстановить резерв.

------------------------------------------------------------------------

# Уровень уверенности

Каждое решение получает уровень уверенности:

-   Высокий;
-   Средний;
-   Низкий.

Если уверенность низкая --- обязательно вывести объяснение причины.

------------------------------------------------------------------------

# Объяснимость

Каждая рекомендация должна содержать:

-   причину;
-   использованные модули;
-   ключевые факторы;
-   ограничения;
-   альтернативы (если имеются).

Пользователь должен понимать, почему принято именно такое решение.

------------------------------------------------------------------------

# Недостаточно данных

Decision Engine обязан вернуть статус «Недостаточно данных», если
отсутствуют критически важные сведения.

Запрещено заменять отсутствие данных положительной рекомендацией.

------------------------------------------------------------------------

# Выходные данные

Для каждого решения формируются:

-   действие;
-   тикер;
-   название;
-   счет;
-   стратегия;
-   сумма;
-   количество;
-   количество лотов;
-   приоритет;
-   уверенность;
-   объяснение.

------------------------------------------------------------------------

# Definition of Done

Decision Engine считается завершенным, если:

-   является единственным источником рекомендаций;
-   объединяет все аналитические модули;
-   каждое решение объяснимо;
-   отсутствуют ложные рекомендации;
-   полностью документирован.
