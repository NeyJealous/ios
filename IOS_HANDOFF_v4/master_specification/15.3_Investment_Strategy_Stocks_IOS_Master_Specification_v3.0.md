# Investment Operating System (IOS)

# Master Specification v3.0

# 15.3 --- Investment Strategy

## Стратегия акций

**Статус:** Каноническая спецификация стратегии инвестирования в акции

## Назначение

Данный документ определяет единые правила отбора, оценки, покупки,
удержания и продажи акций.

------------------------------------------------------------------------

# Главная цель

Покупать качественные компании по справедливой или привлекательной цене
с горизонтом инвестирования более 10 лет.

------------------------------------------------------------------------

# Основные принципы

Приоритеты оценки:

1.  Качество бизнеса.
2.  Финансовая устойчивость.
3.  Конкурентные преимущества.
4.  Рост прибыли.
5.  Рост свободного денежного потока.
6.  Дивидендная политика.
7.  Оценка стоимости.
8.  Рыночный режим.

Высокая ожидаемая доходность никогда не должна компенсировать низкое
качество бизнеса.

------------------------------------------------------------------------

# Используемые источники

-   Investment Universe
-   Company Rating
-   Knowledge Engine
-   Market Regime
-   Portfolio Engine
-   Decision Engine

------------------------------------------------------------------------

# Критерии оценки

Каждая компания оценивается по направлениям:

-   качество бизнеса;
-   прибыль;
-   выручка;
-   свободный денежный поток;
-   долговая нагрузка;
-   рентабельность;
-   дивиденды;
-   оценка стоимости;
-   ликвидность;
-   отраслевые риски;
-   корпоративное управление.

Каждый критерий имеет собственный вес.

------------------------------------------------------------------------

# Категории компаний

-   Компании роста.
-   Дивидендные компании.
-   Защитные компании.
-   Циклические компании.
-   Государственные компании.
-   Высокорискованные компании.

Категория влияет на правила оценки, но не является рекомендацией.

------------------------------------------------------------------------

# Правила покупки

Покупка возможна только при соблюдении всех условий:

-   инструмент входит в Investment Universe;
-   рейтинг выше минимального порога;
-   стратегия допускает покупку;
-   Portfolio Engine не выявил критических ограничений;
-   Reserve Engine не требует первоочередного восстановления резерва;
-   данных достаточно.

------------------------------------------------------------------------

# Правила докупки

Докупка допускается если:

-   доля ниже целевой;
-   рейтинг не ухудшился;
-   отсутствуют критические риски;
-   сохраняется соответствие стратегии.

------------------------------------------------------------------------

# Правила удержания

Статус "Держать" используется если:

-   фундаментальная оценка остается высокой;
-   позиция соответствует целевой структуре;
-   отсутствуют причины для сокращения.

------------------------------------------------------------------------

# Правила сокращения

Основания:

-   существенное превышение целевой доли;
-   ухудшение качества бизнеса;
-   изменение стратегии;
-   необходимость ребалансировки.

------------------------------------------------------------------------

# Правила продажи

Продажа рассматривается только при наличии объективной причины:

-   фундаментальная деградация бизнеса;
-   исключение из Investment Universe;
-   критические корпоративные события;
-   изменение стратегии.

Краткосрочное снижение цены не является самостоятельной причиной
продажи.

------------------------------------------------------------------------

# Недостаточно данных

При отсутствии критически важных фундаментальных показателей система
обязана вернуть статус:

"Недостаточно данных"

Покупка запрещена.

------------------------------------------------------------------------

# Взаимодействие

Результаты стратегии используются:

-   Company Rating;
-   Portfolio Engine;
-   Advisor;
-   Decision Engine.

------------------------------------------------------------------------

# Definition of Done

Стратегия акций считается реализованной если:

-   все критерии документированы;
-   рекомендации воспроизводимы;
-   отсутствуют необъяснимые покупки;
-   используется единая система рейтингов.
