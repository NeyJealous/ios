# Investment Operating System (IOS)

# Master Specification v3.0

# 13 --- Knowledge Engine

**Статус:** Каноническая спецификация Knowledge Engine

## Назначение

Knowledge Engine объединяет разрозненные данные и превращает их в
объяснимые знания, которые используются аналитическими модулями и
Decision Engine.

Knowledge Engine не принимает инвестиционных решений. Его задача ---
предоставить контекст.

------------------------------------------------------------------------

# Цели

-   Централизовать знания о рынке.
-   Исключить дублирование вычислений.
-   Повысить объяснимость рекомендаций.
-   Хранить интерпретации, а не сырые данные.

------------------------------------------------------------------------

# Место в архитектуре

``` text
Providers
↓
Raw Data
↓
Facts
↓
Features
↓
Knowledge Engine
↓
Ratings
↓
Decision Engine
```

Knowledge Engine не обращается напрямую к пользовательским листам.

------------------------------------------------------------------------

# Источники знаний

Используются:

-   Facts;
-   Features;
-   Market Regime;
-   Inflation;
-   Ключевая ставка ЦБ;
-   Bond Engine;
-   Company Rating;
-   Investment Universe;
-   История портфеля.

------------------------------------------------------------------------

# Категории знаний

## Рыночные

-   текущий режим рынка;
-   уровень ставок;
-   инфляционная среда;
-   привлекательность классов активов.

## По инструментам

-   защитный актив;
-   инструмент роста;
-   дивидендный актив;
-   резервный инструмент;
-   подходит для купонной лестницы;
-   недостаточно данных.

## По портфелю

-   концентрация;
-   диверсификация;
-   качество денежного потока;
-   качество резервов;
-   уровень риска.

------------------------------------------------------------------------

# Принципы

Knowledge Engine:

-   не хранит историю сделок;
-   не хранит пользовательские настройки;
-   не заменяет Decision Engine;
-   не выполняет API-запросов.

------------------------------------------------------------------------

# Использование

Результаты используют:

-   Bond Engine;
-   Company Rating;
-   Portfolio Engine;
-   Reserve Engine;
-   Advisor;
-   Decision Engine.

------------------------------------------------------------------------

# Объяснимость

Каждый вывод должен иметь:

-   источник данных;
-   правило формирования;
-   дату последнего обновления.

Если происхождение знания нельзя объяснить, оно не должно
использоваться.

------------------------------------------------------------------------

# Кэширование

Knowledge Engine обязан использовать:

-   готовые Facts;
-   готовые Features;
-   существующий CacheService.

Повторный расчет допускается только при изменении входных данных.

------------------------------------------------------------------------

# Контроль качества

Запрещено:

-   использовать устаревшие знания без проверки;
-   делать выводы при недостатке данных;
-   создавать скрытые правила вне документации.

------------------------------------------------------------------------

# План развития

В будущих версиях возможно добавление:

-   макроэкономических сценариев;
-   отраслевых моделей;
-   оценки качества денежного потока;
-   анализа сезонности;
-   исторической эффективности рекомендаций.

Все новые знания должны быть задокументированы до реализации.

------------------------------------------------------------------------

# Definition of Done

Knowledge Engine считается завершенным, если:

-   знания формируются централизованно;
-   отсутствует дублирование логики;
-   каждый вывод объясним;
-   используется всеми аналитическими модулями;
-   полностью описан в Master Specification.
