# Investment Operating System (IOS)

# Master Specification v3.0

# 28 --- Google Sheets UX Specification

**Статус:** Каноническая спецификация пользовательского интерфейса

## Назначение

Документ определяет единый стандарт оформления Google Sheets,
обеспечивая понятный, последовательный и полностью русскоязычный
интерфейс Investment Operating System.

------------------------------------------------------------------------

# Основные принципы

1.  Пользователь видит только бизнес-информацию.
2.  Вся техническая информация скрыта.
3.  Один экран --- одна задача.
4.  Все действия должны быть очевидны.
5.  Интерфейс полностью на русском языке.

------------------------------------------------------------------------

# Структура листов

Листы делятся на категории:

## Главные

-   Главная
-   Советник
-   План сделок

## Управление

-   Счета
-   Стратегии
-   Стратегии счетов
-   Настройки

## Данные

-   Портфель
-   Сделки
-   Справочник
-   Investment Universe

## Аналитика

-   Portfolio Health
-   Bond Engine
-   Company Rating
-   Решения
-   Факты
-   Признаки

## Служебные

-   Журнал
-   Диагностика
-   Data Cache

По умолчанию служебные листы скрыты.

------------------------------------------------------------------------

# Единые правила отображения

Даты: - ДД.ММ.ГГГГ

Деньги: - ₽ с разделителем тысяч

Проценты: - XX,XX %

Количество: - без лишних знаков после запятой

------------------------------------------------------------------------

# Цветовая схема

🟢 Хорошо

🟡 Требует внимания

🔴 Требуется действие

🔵 Информация

⚪ Недостаточно данных

Цвет никогда не является единственным способом передачи информации ---
обязательно присутствует текст.

------------------------------------------------------------------------

# Пользовательские сообщения

Разрешены:

-   Данные обновлены
-   Требуется обновление
-   Недостаточно данных
-   Выполняется синхронизация
-   Ошибка обновления

Запрещены:

-   Stack Trace
-   Exception
-   JSON
-   FIGI
-   UID
-   Account_ID
-   Strategy_ID
-   Rule_ID

------------------------------------------------------------------------

# Кнопки

Основные действия:

-   Быстро обновить
-   Полная синхронизация
-   Пересчитать рекомендации
-   Настройки
-   Диагностика
-   Справка

Названия должны совпадать во всех меню.

------------------------------------------------------------------------

# Советник

Каждая рекомендация содержит:

-   инструмент;
-   действие;
-   причину;
-   сумму;
-   количество;
-   количество лотов;
-   счёт;
-   стратегию;
-   уровень уверенности.

Не допускаются пустые строки и рекомендации на 0 ₽.

------------------------------------------------------------------------

# Главная

Главная страница отображает:

-   стоимость портфеля;
-   структуру активов;
-   состояние резерва;
-   Portfolio Health;
-   количество рекомендаций;
-   дату последнего обновления;
-   текущий режим рынка.

------------------------------------------------------------------------

# Доступность

Интерфейс должен оставаться удобным:

-   на широком мониторе;
-   на ноутбуке;
-   при масштабировании браузера.

------------------------------------------------------------------------

# Definition of Done

Интерфейс считается завершённым, если:

-   полностью русскоязычный;
-   не отображает технические данные;
-   единообразен на всех листах;
-   понятен без изучения документации.
