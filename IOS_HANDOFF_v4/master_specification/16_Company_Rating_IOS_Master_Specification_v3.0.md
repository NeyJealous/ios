# Investment Operating System (IOS)

# Master Specification v3.0

# 16 --- Company Rating

**Статус:** Каноническая спецификация системы рейтинга компаний

## Назначение

Company Rating --- единая система фундаментальной оценки акций.

Она отвечает **только за качество компании**, а не за принятие
инвестиционного решения. Итоговую рекомендацию формирует исключительно
Decision Engine.

------------------------------------------------------------------------

# Цели

-   объективно сравнивать компании;
-   исключить субъективные оценки;
-   использовать единый алгоритм скоринга;
-   предоставлять объяснимый рейтинг.

------------------------------------------------------------------------

# Источники данных

Используются:

-   Investment Universe;
-   Facts;
-   Features;
-   Knowledge Engine;
-   Market Regime.

При отсутствии обязательных данных рейтинг не рассчитывается.

------------------------------------------------------------------------

# Архитектура рейтинга

Итоговая оценка складывается из независимых блоков:

1.  Качество бизнеса.
2.  Финансовая устойчивость.
3.  Рост бизнеса.
4.  Эффективность.
5.  Дивидендная политика.
6.  Оценка стоимости.
7.  Риск.
8.  Ликвидность.

Каждый блок имеет собственный вес.

------------------------------------------------------------------------

# Качество бизнеса

Оцениваются:

-   конкурентные преимущества;
-   положение на рынке;
-   стабильность прибыли;
-   устойчивость бизнес-модели;
-   качество корпоративного управления.

------------------------------------------------------------------------

# Финансовая устойчивость

Анализируются:

-   долговая нагрузка;
-   покрытие процентов;
-   денежные средства;
-   свободный денежный поток;
-   структура капитала.

------------------------------------------------------------------------

# Рост

Оцениваются:

-   рост выручки;
-   рост прибыли;
-   рост FCF;
-   прогноз развития.

Высокий рост не компенсирует высокий риск.

------------------------------------------------------------------------

# Дивиденды

Учитываются:

-   стабильность выплат;
-   темпы роста;
-   коэффициент выплат;
-   устойчивость дивидендной политики.

Отсутствие дивидендов не является автоматическим недостатком.

------------------------------------------------------------------------

# Оценка стоимости

Используются фундаментальные мультипликаторы.

Компания может получить высокий рейтинг только при разумной оценке
стоимости.

------------------------------------------------------------------------

# Недостаток данных

Если отсутствуют ключевые показатели:

-   рейтинг не рассчитывается;
-   статус: "Недостаточно данных".

Запрещено присваивать положительный рейтинг по неполным данным.

------------------------------------------------------------------------

# Выходные данные

Формируются:

-   итоговый рейтинг;
-   рейтинг по блокам;
-   сильные стороны;
-   слабые стороны;
-   уровень уверенности;
-   объяснение оценки.

------------------------------------------------------------------------

# Использование

Company Rating используется:

-   Decision Engine;
-   Advisor;
-   Portfolio Engine;
-   Investment Strategy.

Самостоятельно рекомендации не формирует.

------------------------------------------------------------------------

# Definition of Done

Модуль считается завершенным, если:

-   использует единый алгоритм оценки;
-   рейтинг воспроизводим;
-   отсутствуют необъяснимые оценки;
-   при нехватке данных возвращает соответствующий статус;
-   полностью документирован.
