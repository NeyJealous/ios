# RFC and ADR Governance

RFC обязателен для изменений:

- архитектуры;
- инвестиционной стратегии;
- модели данных;
- production influence;
- governance;
- security;
- recovery.

Жизненный цикл:

```text
Idea
→ RFC
→ Discussion
→ Approval
→ ADR
→ Master Specification
→ Implementation
→ Review
→ Tests
→ Acceptance
→ Merge
→ Project History
```

ADR не переписывается задним числом.
