# Security and Privacy

Запрещено публиковать:

- tokens;
- cookies;
- Authorization headers;
- `.clasprc.json`;
- `.env`;
- full Account ID;
- full Script ID;
- private API payloads;
- private backups;
- real recovery checkpoints.

Различаются `CURRENT_TREE_PRIVACY` и `HISTORICAL_PRIVACY`.
