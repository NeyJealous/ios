# Управление счетами

Откройте `Инвестиционный помощник → Счета → Настроить счета`.

1. Проверьте имя, тип и masked ID нужного счёта.
2. Выберите preset либо настройте пять переключателей.
3. Укажите причину.
4. Нажмите «Предпросмотр».
5. Изучите API, расчётное, UI и recommendation impact.
6. При критическом изменении установите отдельное подтверждение и повторите preview.
7. Только после корректного preview нажмите «Применить».

Важно:

- Display не включает Calculation автоматически.
- Recommendations требуют Calculation.
- History может быть включена при Calculation=false.
- Отключение History не удаляет существующие данные.
- Включение исключённого счёта не восстанавливает архив.
- Для восстановления данных требуется отдельная migration.
- История флагов доступна через меню «История изменений».
- Rollback восстанавливает только flags.

Known external risk: legacy Market Regime multiplier > 1 может влиять на buy priority через Decision Engine / Rule R030. Account UI не изменяет и не исправляет этот риск.
