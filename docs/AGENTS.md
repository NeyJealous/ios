# Scoped documentation instructions

Наследовать корневые правила без ослабления. Проверять трассируемость к Master
Specification/RFC/ADR, отсутствие секретов и абсолютных локальных путей. Не
помечать решение `ACCEPTED` и не заявлять `PASS` без evidence и требуемого
owner approval. Пользовательские отчёты и UI-тексты писать по-русски.
