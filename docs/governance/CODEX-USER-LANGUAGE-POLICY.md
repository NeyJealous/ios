# Политика языка пользовательских материалов CODEX

## Обязательное правило

Все пользовательские ответы, отчёты о выполнении, пояснения, сводки,
предупреждения, запросы разрешений и итоговые сообщения должны быть написаны
на русском языке.

Правило распространяется на все последующие этапы проекта, включая
`CODEX-05`, `CODEX-06A` и дальнейшие gate-отчёты.

## Допустимые исключения

В исходном техническом виде разрешено оставлять только:

- имена файлов;
- имена веток;
- commit hash;
- Git-команды;
- названия функций, переменных, классов и констант;
- технические статусы и коды ошибок, являющиеся частью контракта;
- точные значения API и GitHub.

Английский технический термин допускается в скобках после русского названия,
если без него теряется точность.

## Требования к изложению

1. Сначала приводится русское объяснение.
2. Затем, при необходимости, приводятся технические значения в исходном виде.
3. Заголовки и обычные пояснительные предложения оформляются на русском языке.
4. Русский и английский языки не смешиваются внутри обычного предложения без
   технической необходимости.
5. Новые Markdown-отчёты для пользователя оформляются преимущественно на
   русском языке.
6. Существующие исторические документы не переписываются только ради
   применения этой политики.

## Управление изменениями

Эта политика является постоянным требованием проекта. Её отмена или изменение
требуют отдельного явного решения пользователя. Применение политики не
разрешает переписывать Git history, изменять существующие commits или менять
техническую логику проекта.
